# Foresee v0.2.0-alpha.1

An MIT-licensed preview of Foresee's native compiler, editor foundation, and auditable AI decision runtime.

## Included

- Native Rust source checking and typed IR generation, covering types, effects, snapshot lineage, and selection ownership.
- A language-server foundation with diagnostics, document symbols, and type/lineage hover.
- Python execution with recoverable SQLite effects, receipts, offline replay, bounded proposal transport, and an opt-in OpenAI adapter.
- An adapter conformance kit for the current Catalog/Patch contract.
- Experimental Ed25519 evidence signing, explicit trust policy, Linux bounded replay, and key-generation/signing/verification commands.

## Downloads and use

Python package version: `0.2.0a1`. Native version: `0.2.0-alpha.1`.

Install the attached wheel with Python 3.11 or newer. To use signatures, install that wheel with the `evidence` extra. The core runtime has no mandatory third-party Python dependencies.

Native archives are provided for Linux x86-64 and macOS Apple Silicon. Extract the archive and run `bin/foresee-semantics` or `bin/foresee-lsp`. Both archives include sample source/IR, a manifest, Cargo dependency inventory, LICENSE, and upstream NOTICE. Verify the attached SHA-256 checksums before use.

## Compatibility and limits

This is an experimental prerelease, not a production-stability or independent security-audit claim. Native effect execution remains in Python. The editor implementation has no completion, rename, or incremental analysis. Older operating systems, Windows native binaries, and other architectures are not validated.

Successful evidence signing and combined verification require Linux. Key files are owner-only but unencrypted. Signatures establish trusted-key endorsement; replay reproduces recorded decisions. Neither proves genuine model/database observations or actual target effects. The worker has resource limits but is not a general OS sandbox.

Combined verification results require an explicit `requirements_satisfied` check; implicit boolean conversion raises `TypeError`. Existing unsigned replay remains unauthenticated. The OpenAI adapter is covered by mock and credential-free tests; live account/model compatibility remains unverified.
